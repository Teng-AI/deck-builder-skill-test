# deck-builder (install test repo)

**Temporary test repository** for the deck-builder skill's install flow. The
permanent home will be announced separately; links to this repo may break
without notice.

Turns an outline and an optional brand kit into a polished institutional
slide deck (HTML, print-ready to PDF). Runs on Claude Code and Codex CLI.

Paste one sentence into your tool:

**Claude Code**

> Clone https://github.com/Teng-AI/deck-builder-skill-test and copy its
> contents into `~/.claude/skills/deck-builder/`, then read that SKILL.md and
> confirm the deck-builder skill is ready.

**Codex CLI**

> Clone https://github.com/Teng-AI/deck-builder-skill-test and copy its
> contents into `~/.codex/skills/deck-builder/`, then read that SKILL.md and
> confirm the deck-builder skill is ready.

Manual steps and the verification command: [INSTALL.md](INSTALL.md).
