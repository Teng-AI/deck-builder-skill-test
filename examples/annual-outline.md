# Harborline Financial Group, FY2026 annual results (worked example, full spine)

*Fictional company, invented numbers, for demonstrating the skill only.
`annual.deck.json` beside this file is the deck.json a run produced from it.
This is the FULL-SPINE example: every one of the template's twelve page
patterns is used, because this outline genuinely earns each one. It is
also the FINISHED example: the user confirmed nothing more is coming, so
the deck carries `"final": true` and the check enforces zero visible
masks - every figure is real, dashed by declaration, or dropped. For the
mid-draft state (gaps still open, honest masks), see the quarterly pair.
Read this pair when the user's outline carries a strategy story
(multi-year arc, targets, delivered commitments) on top of the results.
For a plain results deck, read the quarterly pair instead, and match
pages to the outline, not to this example.*

## What the user handed over

Full-year results notes plus the investor-day material: the firm set a
strategic review in 2022 and this deck reports the fourth year against it.
Same brand kit as the quarterly example (burgundy `#5c1f2e`, accent
`#7a2740`, ochre `#6e5518` secondary), no logo. One balance date only
(December 31, 2026), so the reconciliation drops its average and extra
as-of columns. Legal supplied safe-harbour text for the prose page. The
user confirmed this is everything: no further data is coming, so the deck

## Shape decisions a reader should notice in annual.deck.json

- **All twelve patterns, earned.** The strategy notes carry the six
  narrative pages; the results notes carry the back half. Module x1 covers
  CIB and the split page covers WRS: split is the alternate segment shape,
  used INSTEAD of a second module, never beside one for the same segment.
- **Every chart is data-driven** (`charts`): two stacked trend charts, the
  three panel pairs, and the module chart, all with user-stated totals.
- **Annual furniture is filled, not kept**: tile periods say FY2026/FY2025,
  the highlights heading says Full-Year, table headers name the years. A
  kept quarterly header on an annual deck is the classic kept-by-accident
  bug.
- **The recon drops compose** (`recon.avg-cols` + `recon.asof-cols-23`):
  one balance date means one column, not four columns of dashes.
