# Harborline Financial Group, 2Q 2026 results (worked example)

*Fictional company, invented numbers, for demonstrating the skill only.
`quarterly.deck.json` beside this file is the deck.json a run produced from it;
read the pair together as the worked example.*

## What the user handed over

Quarterly results notes, two segments. They asked for "a results deck like the
big banks publish", supplied brand colours (primary deep burgundy `#5c1f2e`,
rule accent `#7a2740`, secondary ochre `#6e5518` when asked for a second hue
for the charts), no logo. Note in `quarterly.deck.json` how those three inputs
become the FULL token set: every chromatic role is derived from them, because a
partial retheme leaves the deck wearing the template's blue beside the brand.
